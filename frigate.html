Frigate NVR

I’m not putting IP cameras on my network without knowing exactly where the footage goes. Frigate is a local NVR that runs in Docker — no cloud, no subscription. Cameras go on VLAN 40, fully isolated, only reachable from the server where Frigate runs. Waiting on the next house move to actually install the cameras.

Planned Setup

Frigate

Docker container on the home server. GPU passthrough already configured for hardware-accelerated video processing.

IP Cameras

PoE cameras powered by a dedicated Netgear PoE switch. Planned for the next house move.

Storage

Recordings stored at /mnt/media/frigate on the dedicated 5TB HDD in the server.

VLAN 40 — Cameras

Fully isolated network. No internet access. Only reachable from VLAN 20 (Servers). Cameras cannot initiate connections to any other device.
